# BACS Account Label (fa)

افزونهٔ کوچک وردپرس برای درگاه «انتقال بانکی مستقیم» (BACS) ووکامرس:

1. اصلاح برچسب فیلدهای حساب بانکی.
2. افزودن یادداشت کوتاه واریز از طریق اپلیکیشن «پل» بالای مشخصات بانکی.

## ۱) مشکل برچسب

در پیشخوان، فیلد `Account number` با عنوان «شماره حساب کاربری» نمایش داده می‌شود، اما در
صفحهٔ «سفارش دریافت شد» و ایمیل سفارش، همان فیلد با عنوان «شماره کارت» چاپ می‌شود.
دلیلش تفاوت ترجمهٔ فارسی همان رشته در دو محل است — این متن در هیچ فیلد قابل‌ویرایشی در
پیشخوان وجود ندارد.

### راه‌حل

این افزونه روی فیلتر `woocommerce_bacs_account_fields` (اولویت ۹۹، بعد از افزونه‌های
فارسی‌ساز) برچسب `account_number` را به «شماره حساب» تغییر می‌دهد. همین یک فیلتر هم
صفحهٔ ثبت سفارش و هم ایمیل سفارش را پوشش می‌دهد، چون هر دو از
`WC_Gateway_BACS::bank_details()` می‌آیند.

## ۲) یادداشت واریز از طریق «پل»

بالای مشخصات بانکی — هم در صفحهٔ «سفارش دریافت شد» و هم در ایمیل سفارش — یک باکس
کوتاه چاپ می‌شود:

> لطفاً مبلغ سفارش را دقیقاً با همین خُرده (۱۵,۰۰۰,۰۰۰ تومان) از طریق اپلیکیشن «پل» واریز کنید.

عبارت `{total}` در متن با مبلغ نهایی همان سفارش جایگزین می‌شود.

برای تغییر متن، تابع `bacs_account_label_notice_text()` را ویرایش کنید، یا بدون
دست‌زدن به فایل افزونه:

```php
add_filter( 'bacs_account_label_notice_text', function () {
    return 'مبلغ {total} را با همین خُرده، از طریق پل واریز کنید.';
} );
```

برای حذف کامل یادداشت، مقدار را به رشتهٔ خالی `''` برگردانید.

## نصب

1. فایل `bacs-account-label.zip` را دانلود کنید.
2. پیشخوان وردپرس → افزونه‌ها → افزودن → بارگذاری افزونه → انتخاب فایل → هم‌اکنون نصب کن.
3. فعال کنید.
4. یک سفارش آزمایشی با روش «انتقال بانکی مستقیم» ثبت کنید و صفحهٔ «سفارش دریافت شد» را ببینید.

> اگر افزونه را قبلاً نصب کرده‌اید، کافی است نسخهٔ جدید را از همان صفحهٔ بارگذاری
> نصب کنید و گزینهٔ «جایگزینی با نسخهٔ بارگذاری‌شده» را بزنید.

## تغییر برچسب‌های دیگر

در فایل `bacs-account-label.php` تابع `bacs_account_label_map()` را ویرایش کنید.
کلیدهای معتبر: `bank_name`، `account_number`، `sort_code`، `iban`، `bic`.

```php
return array(
    'account_number' => 'شماره حساب',
    'iban'           => 'شماره شبا',
);
```

یا بدون دست‌زدن به فایل افزونه، از فیلتر خودش استفاده کنید:

```php
add_filter( 'bacs_account_label_map', function ( $map ) {
    $map['iban'] = 'شماره شبا';
    return $map;
} );
```
